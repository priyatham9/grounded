# Contributing

## Running Tests

This repository is a static HTML site with no test suite. There is no build step and no runtime dependencies beyond two webfonts.

## Dependency Policy

This project uses only:
- HTML5, CSS3, and vanilla JavaScript
- Two external webfonts (Archivo and IBM Plex Mono) from Google Fonts

No runtime npm packages, no build tooling, and no server-side code.

## Numbers and Data

Empirical figures on the page come from real public OSHA Injury Tracking Application data. Every figure must be produced by a committed script in one of the six supporting repositories and transcribed with attribution.

No estimate, external source, or hand-typed value may appear on the page without:
1. A committed script that produced it, or
2. An explicit citation with a link to the primary source

## Synthetic Data

This repository contains no synthetic data. The six supporting repositories have dedicated `synthetic/` directories; see their individual CONTRIBUTING files for policy on generated data.
