The denominator

02

Persistence

27.2% vs 0.95%

An establishment flagged as implausible gets flagged again the next year 27.2% of the time, against 0.95% for one that was never flagged, so the same handful of filers likely account for a disproportionate share of the noise.

The cost model

The published loading-station example books $55,000 in incident cost on the traditional ledger and carries $63,000 more that only the human-capital ledger counts, which can flip an investment from a fail to a pass depending on which ledger is used.
